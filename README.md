# intraday-slot-winrate-strategy

日本株の30分足を9:00〜15:30まで30分刻み(11区間)に分割し、各区間の「直近30日ローリング」の陽線/陰線出現数から
30日勝率を算出、判定に応じてロング/ショートに自動転換するPineScriptストラテジーと、そのバックテスト結果
(Strategy Tester + Data Window)をTradingViewから自動取得するPlaywrightスクリプトのセット。

## ファイル構成

- `intraday-slot-winrate-strategy.pine`
  TradingView Pine Editorに貼り付けて使うストラテジー本体。30分足チャート専用。
- `tv_backtest_scraper_intraday_slot.py`
  TradingView画面をPlaywrightで自動操作し、Strategy Testerの主要指標(総損益・最大ドローダウン・
  プロフィットファクター)と、Pine側がData Windowに出力する区間ごとの30日勝率%・30日平均変化%を
  取得してCSV保存する。
- `merge_intraday_slot_csv.py`
  `csv/`配下の銘柄別CSVを1つのCSV(`merged_all_symbols.csv`)に横持ち統合する。
- `format.csv` (別途用意)
  取得対象銘柄コードを列挙する入力ファイル。`銘柄コード`列が必須。
- `csv/`
  スクレイパーの出力先フォルダ(自動作成)。

## Pineスクリプトの使い方

1. TSE銘柄の**30分足チャート**にこのスクリプトを適用する(30分足以外はエラーで停止)。
2. 「最低サンプル日数」(初期値120、`lookbackMinCount`)でデータ不足時の誤判定を抑制する。
3. 判定ロジック(エントリー可否):
   - **全期間累積**(スクリプト適用開始からの通算)で各区間の陽線比率を集計
   - 累積サンプル数が`lookbackMinCount`未満なら「データ不足」でエントリーなし
   - 全期間勝率 > 50% → 「上昇」判定 → ロングエントリー
   - 全期間勝率 < 50% → 「下落」判定 → ショートエントリー
   - ※ 後述の「30日ローリング統計」はこの判定には使わず、表示・分析専用の別集計
4. 決済ロジック:
   - 通常は逆シグナルへの自動転換(ドテン)
   - 最終区間(15:00-15:30)は判定結果に関わらず「大引け前に手仕舞い」を**最優先**で実行し、
     ポジションを翌日以降に持ち越さない(以前は判定分岐の`else if`に埋もれており、
     最終区間で方向判定が出るとポジションが持ち越されるバグがあったため修正済み)
5. チャート右上に区間別(30日陽線数・30日陰線数・30日勝率%・30日平均変化%)の成績表を表示。
6. スクリプト末尾で全11区間について、直近30日ローリングの「勝率%」「平均変化%
   ((終値−始値)/始値×100 の30日平均)」をData Windowに出力する
   (Playwrightスクレイパーがここを読み取る)。60日・120日ウィンドウは廃止済み。

## Pythonスクレイパーの使い方

### 事前準備

```
pip install playwright
playwright install chromium
```

`format.csv` を用意し、`銘柄コード` 列に対象銘柄(例: 3103)を1行1銘柄で記載する。

### 実行

```
python tv_backtest_scraper_intraday_slot.py
```

初回実行時はブラウザが開くので、以下を手動で行ってからターミナルでEnterを押す。

1. TradingViewにログイン
2. `intraday-slot-winrate-strategy.pine` を適用したチャートを開く
3. Strategy Testerパネルを表示
4. データウィンドウを開く

以降は銘柄を自動的に切り替えながら、`csv/銘柄コード_日付.csv` に
Strategy Testerの主要指標(総損益・最大ドローダウン・プロフィットファクター)と、
区間別の30日勝率%・30日平均変化%を保存する。

複数銘柄のCSVをまとめる場合は続けて実行する。

```
python merge_intraday_slot_csv.py
```

`csv/merged_all_symbols.csv` に銘柄ごと1行で全指標が横持ち統合される。

### 注意点

- `DW_ANCHOR_KEYS`(スクレイパー側)とPineスクリプトの`plot(..., title=...)`のタイトル文字列は
  完全一致している必要がある。Pine側で区間や表示項目を変更した場合は
  `DW_ANCHOR_KEYS` も同じ内容に合わせて修正すること。
- Data Windowはcanvas描画ではなくDOM要素なので、`plot(..., display=display.data_window)`
  経由で出力した値のみ本スクリプトで取得できる。`table.new()`のチャート内テーブル自体は
  DOM上のテキストノードとして存在しないため直接は取得できない。
- **勝率%・プロフィットファクターが`-`(値なし)になるケース**: 該当期間中に決済(クローズ)済みの
  トレードが1件もない場合(例: 最終区間で建てたポジションが評価損のまま未決済、等)、
  TradingView側はこれらの指標を算出不能として`-`表示する。総損益・最大ドローダウンは
  未決済の含み損益込みで表示されるため非ゼロでも矛盾ではない。スクレイパー側は`-`を
  「算出不可」として値なしのまま記録する(数値0への丸め換算はしない)。
- 整合性チェック(`is_dw_consistent`)は「総損益が非ゼロなのにData Windowが空」の場合のみ
  再取得する簡易版。より厳密なチェックが必要な場合は用途に応じて調整する。
